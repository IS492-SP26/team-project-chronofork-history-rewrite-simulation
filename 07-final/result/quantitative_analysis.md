# Pilot Study Quantitative Analysis Report

**Study:** ChronoFork (dynamic AI) vs IDN-Twine (static predefined branches)
**Design:** Within-subject, N=6
**Date:** 2026-04-30

---

## 1. Methodology Notes

- All Likert items scored on a 7-point scale (1=Strongly Disagree, 7=Strongly Agree) unless noted otherwise.
- Reverse-scored items (marked R) transformed via `8 - raw_score` before computing subscale means.
- Reverse-scored items: A1 data items 1-6 (Narrative Understanding & Attentional Focus), B1 data item 25 (PENS controlled/pressured), D data items 32-33 (IMI Interest/Enjoyment: boring, did not hold attention), D data items 44,46 (IMI Pressure/Tension: not nervous, very relaxed).
- Paas Mental Effort uses 9-point scale (1=very very low, 9=very very high) and is reported separately.
- With N=6, no inferential statistics are reported; only descriptive statistics and effect directions.
